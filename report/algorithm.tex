In this section, we describe how we have designed the evolutionary algorithm for optimizing the distribution of activation functions in the hidden layer(s) of a neural network.

\subsection{Encoding}
In this Work, we consider a neural network with one or more hidden layers.

Let \(v=\{v_1, v_2, \dots, v_n\} \) be a raw output of the hidden layer and 
\(f = \{f_1, f_2, \dots, f_n\}\) be the activation functions applied to each neuron in the hidden layer, respectively,
where \(f_i \in \mathcal{F}\) for \(i=1,\dots,n\) and \(\mathcal{F}\) is the set of activation functions (we call \(\mathcal{F}\) the ``function pool'').
Let \(\{B_0, \dots, B_m\}\) be the set of mini-batches with fixed size, i.e., $m$ partitions of the full training dataset $B$.

In the context of the evolutionary algorithm, $f$ also serves directly as the genotype
of an individual. 

The phenotype is constructed directly from this genotype. 
Each gene $f_i$ is assigned to neuron $i$'s activation function.
The phenotype is therefore the configuration of activation functions in the hidden layer.

For example, for a hidden layer $v = \{v_1, v_2, v_3, v_4\}$ and $\mathcal{F} = \{\text{ReLU}, \text{Tanh}, \text{Sigmoid}\}$,
the individual $f = (\text{ReLU}, \text{Tanh}, \text{Tanh}, \text{Sigmoid})$
assigns ReLU to $v_1$, Tanh to $v_2$ and $v_3$, and Sigmoid to $v_4$.

\subsection{Fitness Evaluation}
Fitness quantifies how well a given activation function assignment $f$ performs
on the current task. It is defined as the network's error on the current
mini-batch $B_b$, computed with the network weights $W$, which is fixed during the evaluation of a generation. 
Because every individual in a generation is
evaluated on the same weights $W$ and the same mini-batch $B_b$, differences in
fitness across individuals can only be attributed to differences in their
activation function assignment, not to differences in training progress.

The weights $W$ are initialized once at
the start of the algorithm. After each generation's selection and mutation
step, $W$ is updated by a single training step on $B_b$, using the newly formed
population $P^{t+1}$. The mini-batch index $b$ then advances by one
($b \leftarrow b+1$). Once all mini-batches have been used, the training set is
reshuffled and $b$ is reset to $0$.

\section{Optimization Process}

An Optimization Algorithm proceeds as follows. 
The population $P^0$ is initialized with $M$ individuals, each a randomly generated genotype.
The network weights $W$ are initialized once randomly.

Each generation $t$ then proceeds in three stages. First, every individual
$P^t_i$ in the current population is evaluated for fitness: its genotype is
decoded into a phenotype (i.e., an activation function assignment), and the
resulting network's error on the current mini-batch $B_b$ is measured with
$W$ held fixed. Second, a new population $P^{t+1}$ is formed
from $P^t$ using tournament selection followed by mutation. 
Third, the network weights $W$ are updated.
For each individual in the new population $P^{t+1}$, one training step is
performed on mini-batch $B_b$ using that individual's activation function
assignment, with each step continuing from the weights produced by the
previous individual's step. In other words, a single shared
weight $W$ is carried through the entire population within a
generation, updated $M$ times in sequence, once per individual, rather
than each individual training its own independent copy of $W$. After all $M$
updates, the mini-batch index advances, cycling back to the start of the
dataset (after reshuffling) once all mini-batches have been used.

After $g$ generations, the champion $C$ is selected as the individual with
the highest fitness in the final population $P^g$, i.e., the best-performing genotype found in the last generation evaluated, not the
best individual seen across the entire run.

\subsection{Retraining}
After the optimization algorithm finishes, we retrain the champion $C$ in isolation. 
A new weight is initialized independently of the weight used in the optimization algorithm, 
and a network using $C$'s activation function assignment is trained for the same number of epochs and over
the same mini-batches using the same procedure as the optimization algorithm.
