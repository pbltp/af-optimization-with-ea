\subsection{Overview}
In this section, we describe how we have designed the evolutionary algorithm for
optimizing the distribution of activation functions in the hidden layer(s) of a neural network.
As an assumption, we consider a neural network with one or more hidden layers.
Let \(v=\{v_1, v_2, \dots, v_n\} \) be a raw output of the hidden layer and 
\(f = \{f_1, f_2, \dots, f_n\}\) be the activation functions applied to each neuron in the hidden layer, respectively,
where \(f_i \in \mathcal{F}\) for \(i=1,\dots,n\) and \(\mathcal{F}\) is the set of activation functions (we call \(\mathcal{F}\) the ``function pool'').
Let \(\{B_0, \dots, B_m\}\) be the set of mini-batches, i.e., $m$ partitions of the full training dataset $B$.
\subsection{Fitness Evaluation}
Fitness is evaluated without any gradient update: the network weights $W$ are held fixed, and the error on the current mini-batch $B_b$ is measured.
All individuals in a given generation are evaluated on the same mini-batch, so fitness differences reflect only the activation function distribution.
The network weights $W$ are initialized once at the start and are updated for every generation using one mini-batch training step on $B_b$.
After each generation, the mini-batch index advances ($b \leftarrow b+1$); once all mini-batches are exhausted, the training set is shuffled and $b$ is reset to $0$.
\subsection{Algorithm}
We use a simple genetic algorithm for the optimization.

\begin{algorithm}[H]
\caption{Optimization of Activation Function Distribution}
\label{alg:optimization}
\begin{algorithmic}[1]
\REQUIRE Population $P$ of size $M$, function pool $\mathcal{F} = \{f_1, \dots, f_n\}$, max generations $g$, mini-batches $\{B_0, \dots, B_m\}$
\STATE Initialize $P^0$ with random functions from $\mathcal{F}$ for each individual $i \in \{1,\dots,M\}$
\STATE Initialize network weights $W$ randomly; set mini-batch index $b \leftarrow 0$
\STATE Evaluate all individuals in $P^0$ on $B_0$ (no training, $W$ fixed)
\FOR{$t = 0$ to $g$}
    \FOR{$i = 1$ to $M$}
        \STATE Evaluate fitness of $P^t_i$ on $B_b$ with $W$ fixed (no training)
    \ENDFOR
    \STATE Select new population $P^{t+1}$ from $P^t$ using selection operator
    \STATE Mutate $P^{t+1}$ using mutation operator
    \FOR{$i = 1$ to $M$}
        \STATE Train $W$ for one step on $B_b$ with activation functions $P^{t+1}_i$
    \ENDFOR
    \STATE $b \leftarrow b + 1$; if $b > m$, shuffle training set and $b \leftarrow 0$
\ENDFOR
\STATE Set champion $C \leftarrow \arg\max_{f \in P^t} fitness(f)$
\RETURN $C$
\end{algorithmic}
\end{algorithm}

\subsection{Retraining}

After the algorithm finishes, the champion $C$ is trained again on a new
set of random weights $W_2$ for the same amount of batches.  This allows
measuring the effectiveness of training on a variable set of activation
functions ($W$) versus a single set of optimized activation functions
($W_2$).

\subsection{Proposal of Operators}
\subsubsection{Selection}
For the selection of individuals from the current generation $P^t$ to the next generation $P^{t+1}$, we use tournament selection. We initially set $k=2$, meaning each tournament involves 2 randomly selected individuals from $P^t$.
\begin{algorithm}[H]
\caption{Selection($k$)}
\label{alg:selection}
\begin{algorithmic}[1]
\WHILE{$P^{t+1}$ is not full}
\STATE Select $k$ individuals from $P^t$ uniformly at random
\STATE Set the best fitting individual as $f_A$
\STATE Select $k$ individuals from $P^t$ uniformly at random again
\STATE Set the best fitting individual as $f_B$
\STATE Execute $Crossover(f_A, f_B)$ with probability $p_c$
\IF {Crossover is executed}
\STATE Add $f_C$ to $P^{t+1}$
\ELSE \STATE Add $\max_{fitness(f)}\{f_A, f_B\}$ to $P^{t+1}$
\ENDIF
\ENDWHILE
\end{algorithmic}
\end{algorithm}
\subsubsection{Crossover}
We use uniform crossover. The algorithm takes two parents as input and returns one child.
The probability of crossover is initially set to $0.8$. Although this probability may be varied in experiments, it will remain high.
\begin{algorithm}[H]
\caption{Crossover($f_A, f_B$)}
\label{alg:crossover}
\begin{algorithmic}[1]
\STATE Initialize $f_C$
\FOR{each $({f_A}_i,{f_B}_i)$ in $f_A, f_B$}
\STATE ${f_C}_i = {f_A}_i$ with probability $0.5$
\STATE Otherwise, ${f_C}_i = {f_B}_i$
\ENDFOR
\RETURN $f_C$
\end{algorithmic}
\end{algorithm}
\subsubsection{Mutation}
Mutation is implemented in the form of randomly drawing functions from the function pool to replace selected elements in an individual.
The probability of mutation $p_m$ is initially set to $0.01$. Although this probability may be varied in experiments, it will remain very low. Mutation is performed for each element in the individual.
\begin{algorithm}[H]
\caption{Mutation($f, l$)}
\label{alg:mutation}
\begin{algorithmic}[1]
\FOR {each element $f_i$ in $f$}
\STATE Replace $f_i$ with a randomly selected $f_s \in \mathcal{F}\setminus\{f_i\}$ with probability $p_m$
\ENDFOR
\end{algorithmic}
\end{algorithm}
